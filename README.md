# GAS Enemy Combat Prototype

A gameplay-focused Unreal Engine 5 prototype demonstrating modern combat architecture using Gameplay Ability System (GAS), AI Perception, Behavior Trees, Gameplay Tags and Animation Blueprints.

## Features

- Gameplay Ability System (GAS)
- Gameplay Effects
- Gameplay Tags
- Health & Stamina Attributes
- Enemy AI
- AI Perception
- Behavior Trees
- Animation Montages
- Health Bar UI
- C++ / Blueprint Hybrid Architecture

## Technologies

- Unreal Engine 5
- C++
- Gameplay Ability System
- Gameplay Tags
- AI Perception
- Behavior Trees
- Animation Blueprint
- Enhanced Input
